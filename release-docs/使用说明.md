# FilmEcho 1.4.3 · Windows 英语电影跟读播放器

解压整个 ZIP 到可写入的文件夹，双击 **英语跟读播放器.exe**。无需编译；请保留 EXE、vendor、runtime 文件夹及许可文件。需要 Windows x64 和 .NET Framework 4.8；本机 OCR、英语朗读还取决于 Windows 的语言和语音组件。

1. 点击“打开电影”或拖入视频，选择英语音轨和所需字幕。打开后默认暂停。
2. Space 播放/暂停；方向键按所选步长跳转；R 重听最近一句。可用句子循环和句尾自动暂停。
3. 点击字幕单词，或输入后回车查词。程序暂停电影，保存词语、原句和位置。离线词库可用，在线词典补充和短语翻译需要网络。
4. 在“本片生词”查看记录，双击或点击“回到原句”重听台词。编辑笔记后点击“保存笔记”；可导出本片生词 CSV。
5. “打开浏览器”启动 Windows 当前默认浏览器，不指定网站，不发送当前单词、原句或笔记。发布版不内嵌 Google 翻译，也不依赖 WebView2。

右上角可切换深浅主题与中文/English。使用分布仅保留地区地图看板。尚未接入全国统计服务，因此不显示虚构使用量；没有示例、导入、刷新、指标选项、统计概览或排行，也不上传使用信息。

右上角“更新”读取官方 GitHub Releases，发现新版本后亮起提示。可查看说明、下载，然后选择“重启并更新”。会保存当前记录、笔记与播放进度，保留学习数据；安装前验证签名和文件哈希。初次公开发布之前可能尚无正式 Release，检查时会说明尚未找到版本。

学习记录和设置保存在程序旁的 `data`，按电影完整路径隔离。关闭播放器后备份完整 `data` 文件夹；更新或移动程序时保留此文件夹。不要删除正在运行的数据库 WAL/SHM 文件。
