# 第三方组件与来源

| 组件 | 用途 | 来源及许可 |
| --- | --- | --- |
| mpv v0.41.0-1109-g36abaa32d | 视频、音频、字幕及 IPC | [20261009 Windows 构建](https://github.com/shinchiro/mpv-winbuild-cmake/releases/tag/20261009)，当前构建启用 GPL；许可及构建说明位于 licenses |
| ECDICT | 离线英汉词库 | [skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)，MIT；见 licenses/ECDICT-MIT.txt |
| Free Dictionary API | 在线英语释义和原声地址 | [服务主页](https://dictionaryapi.dev/)，在线服务受服务方可用性限制 |
| MyMemory | 短语英译中 | [服务说明](https://mymemory.translated.net/doc/spec.php)，在线服务受免费额度和可用性限制 |
| Windows OCR / SAPI / winsqlite3 | 本机识别、朗读及数据库 | 使用 Windows 系统组件，不打包系统 DLL |
| DataV GeoAtlas | 省界及南海诸岛地图 | [官方区域工具](https://datav.aliyun.com/portal/school/atlas/area_selector)，地图内嵌在 EXE；来源记录见 licenses/china-boundaries-source.md |

发布版没有 WebView2 运行依赖，不内嵌 Google 翻译页面。mpv 为独立进程，通过公开 JSON IPC 接口通信，未修改它的源码。

二进制分发仍须满足第三方许可。随包 GPL 文本和通用构建说明本身不等于完整的对应源码提供方式；正式公开发布前须核对 mpv 及依赖的准确对应源码和构建材料。该要求应与是否附带 FilmEcho 自有 C# 源码分别处理。
